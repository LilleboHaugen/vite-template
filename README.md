# Vite+ Template

A minimal React starter built on [Vite+](https://viteplus.dev) and pnpm.

## Stack

- React 19 with the React Compiler
- TypeScript
- Tailwind CSS v4
- shadcn/ui on Base UI
- Light/dark theme toggle out of the box

## Getting started

```sh
vp install
vp dev
```

## Commands

| Command      | Description                  |
| ------------ | ---------------------------- |
| `vp dev`     | Start the dev server         |
| `vp build`   | Build for production         |
| `vp preview` | Preview the production build |
| `vp lint`    | Lint the project             |

## Adding components

```sh
vp dlx shadcn@latest add <component>
```
