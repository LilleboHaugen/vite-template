# vite-template

Minimal React + TypeScript starter built on Vite.

## Stack

- React 19 with React Compiler
- Vite
- Tailwind CSS v4 + shadcn/ui (Base UI)
- Oxlint + Oxfmt
- Bun

## Getting started

```sh
bun install
bun run dev
```

## Scripts

| Command           | Description                         |
| ----------------- | ----------------------------------- |
| `bun run dev`     | Start the dev server                |
| `bun run build`   | Run checks and build for production |
| `bun run preview` | Preview the production build        |
| `bun run check`   | Format, lint and type-check         |
